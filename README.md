## Project Overview

This project focuses on analyzing banking loan data to gain meaningful insights into loan distribution, funding performance, collections, interest revenue, and customer demographics.

The dashboard provides an interactive view of key banking metrics, helping stakeholders monitor loan performance and make data-driven business decisions.

## Key Performance Indicators (KPIs)

* Total Loan Amount Funded

* Total Loans Issued

* Total Collection

* Total Interest Earned

* Branch-wise Interest and Fees

* State-wise Loan Distribution

* Religion-wise Loan Distribution

* Top 10 Branches by Loan Amount

## Tools & Technologies

* Microsoft Power BI

* Tableau

* Microsoft Excel

* Data Cleaning and Data Visualization

* Data Analysis

## Key Insights

* Analysis of overall loan funding and collection performance.

* Identification of top-performing branches.

* Understanding loan distribution across different states.

* Analysis of customer demographics and loan trends.

* Monitoring interest and fee generation.

## Project Objective

To transform raw banking loan data into meaningful visual insights through interactive dashboards, supporting better business analysis and informed decision-making.
